# Kapibara Riot

[English](README.md)

Невелика гра-платформер. Ці кроки для Windows. Можна користуватися GitHub Desktop або git у терміналі. Меню GitHub Desktop англійською.

## Встанови програми один раз

### Rust

Відкрий https://rustup.rs, завантаж `rustup-init.exe` і запусти його. Коли програма запитає, що робити, обери звичайне встановлення: натисни `1`, потім Enter.

Якщо вона напише, що бракує Visual Studio або C++ build tools, спочатку встанови їх: https://visualstudio.microsoft.com/visual-cpp-build-tools/

У тому інсталяторі познач набір **Desktop development with C++**. Після цього знову запусти `rustup-init.exe`.

### make

1. Натисни клавішу Windows.
2. Напиши `Термінал`. Якщо Windows англійською, напиши `Terminal`.
3. Натисни Enter.
4. У вікні, що відкрилось, напиши це і натисни Enter:

```
winget install ezwinports.make
```

5. Коли встановлення закінчиться, закрий термінал. Windows не бачить нові команди у вікні, яке вже було відкрите.

### Git, якщо ти не користуєшся GitHub Desktop

Завантаж інсталятор з https://git-scm.com/download/win і запусти його. Звичайні варіанти підходять. Залиш увімкненим пункт «Git from the command line and also from 3rd-party software». У GitHub Desktop git уже є, тож цей крок можна пропустити, якщо користуєшся цією програмою.

## Завантаж гру один раз

### Через GitHub Desktop

1. Відкрий GitHub Desktop.
2. У меню зверху натисни **File**, потім **Clone repository**.
3. Відкрий вкладку **URL**.
4. Встав цю адресу:

```
https://github.com/home-gd/kapibara-riot
```

5. Місце на диску можна не змінювати. Зазвичай це `C:\Users\ТвоєІм'я\Documents\GitHub\kapibara-riot`.
6. Натисни **Clone**.

### Через git у терміналі

Відкрий новий термінал і вводь команди по одній. Після кожної натискай Enter і зачекай, поки вона закінчиться.

```
git clone https://github.com/home-gd/kapibara-riot.git
cd kapibara-riot
```

Папка `kapibara-riot` з’явиться там, де термінал був відкритий. Зазвичай це `C:\Users\ТвоєІм'я\kapibara-riot`.

## Запусти гру

Перший запуск збирає гру. Це може тривати кілька хвилин, і вікно гри з’явиться лише після збірки. Наступні запуски швидші.

Не закривай термінал, поки граєш. Якщо його закрити, закриється і гра.

Якщо вікно пише, що `make` не розпізнано, Windows ще не бачить встановлення. Закрий вікно і відкрий нове.

### Через GitHub Desktop

1. Перевір, що зверху назва сховища — **kapibara-riot**.
2. У меню зверху натисни **Repository**.
3. Натисни **Open in PowerShell** або **Open in Command Prompt**. Назва залежить від налаштування GitHub Desktop. Підходить будь-який із цих пунктів.
4. Відкриється вікно вже в папці гри. Напиши це і натисни Enter:

```
make run
```

### Через git у терміналі

Відкрий новий термінал. Якщо ти щойно завантажила гру і все ще в папці `kapibara-riot`, напиши:

```
make run
```

Якщо запускаєш пізніше, спочатку перейди в папку:

```
cd kapibara-riot
make run
```

Якщо `cd kapibara-riot` пише, що папки немає, цей термінал відкритий не в тій папці, де ти завантажувала гру. Новий термінал починає роботу у твоїй папці користувача.

## Коли гру оновили

Перед оновленням закрий гру і вікно, з якого вона запускалась.

### Через GitHub Desktop

1. Відкрий GitHub Desktop на сховищі **kapibara-riot**.
2. Натисни **Fetch origin**. Якщо кнопка зміниться на **Pull origin**, натисни і її.
3. Знову відкрий папку гри: **Repository**, потім **Open in PowerShell** або **Open in Command Prompt**.
4. Напиши `make run` і натисни Enter.

### Через git у терміналі

```
cd kapibara-riot
git pull
make run
```

## Керування

- Рух: A і D або стрілки вліво і вправо. Якщо затиснути обидві сторони разом, персонаж стоїть.
- Стрибок: пробіл, W або стрілка вгору. Коротке натискання — низький стрибок. Якщо тримати клавішу, стрибок вищий.
- Щоб провалитися крізь платформу, затисни S або стрілку вниз і натисни пробіл. Крізь землю так провалитися не можна.
